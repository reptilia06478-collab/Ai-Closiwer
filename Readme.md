## 🎯 Cara Pakai

### 1. Buka Website
https://reptilia06478-collab.github.io/Ai-Closiwer/

### 2. Aktifkan AI Asli (GRATIS)
1. Klik tombol **DEV** di kanan atas
2. Daftar gratis di [console.groq.com/keys](https://console.groq.com/keys)
3. Copy API Key
4. Paste di form → **Simpan**
5. **SELESAI!** AI siap dipakai unlimited

### 3. Install sebagai App
1. Buka website di Chrome
2. Tap menu (⋮) → **"Add to Home Screen"**
3. Icon CLOSIWER muncul di home screen
4. Buka kayak app biasa!
